Chapter 1
Getting Started
HubSphere Enterprise V3 is a comprehensive multi-tenant SaaS platform that combines Customer Relationship Management (CRM), Human Resource Management System (HRMS), Communication, Automation, Analytics, and AI-powered insights into a single unified application. This guide walks you through every feature, from initial login to advanced automation workflows, ensuring that both company users and super administrators can fully leverage the platform.
The platform is built on a modern technology stack including Next.js, Supabase PostgreSQL, and Prisma ORM, deployed on Vercel for reliable, scalable access. It supports 13 distinct user roles with over 224 fine-grained permissions, ensuring that every team member has exactly the right level of access. Whether you are a sales executive managing leads, an HR manager handling payroll, or a super administrator overseeing multiple tenants, this guide covers every workflow you will encounter.
Access URL: Open your web browser and navigate to the HubSphere Enterprise V3 production URL. The platform is optimized for modern browsers including Chrome, Firefox, Safari, and Edge.
System Requirements

HubSphere is a web-based application that runs in any modern browser. No desktop installation is required. For the best experience, use a screen resolution of 1280x720 or higher with a stable internet connection. Mobile devices are supported for basic viewing, but administrative tasks are recommended on desktop or laptop computers for optimal productivity.

Chapter 2
Authentication and Login
HubSphere uses a secure JWT-based authentication system with access tokens (15-minute expiry) and refresh token rotation (30-day expiry). All tokens are stored as HTTP-only, secure, SameSite=Lax cookies, providing robust protection against token theft and cross-site request forgery. The platform also supports TOTP-based two-factor authentication for privileged accounts.
2.1 Initial Setup
When you first access the platform, you will be guided through the initial setup process. The super administrator account is created first, which then becomes the primary account for managing the entire tenant organization. Follow these steps to complete the initial setup:
  1. Navigate to the application URL in your web browser. You will see the setup page if no administrator account exists yet.
  2. Enter your details: Provide your full name, email address, and a strong password (minimum 8 characters with uppercase, lowercase, number, and special character).
  3. Organization configuration: Enter your company name (this creates your tenant), select your industry, and configure your timezone and date format preferences.
  4. Complete setup: Click the "Create Account" button. The system will create your super administrator account, the default tenant organization, and assign you the TENANT_OWNER role with full permissions.
Important: The initial setup can only be performed once. After the first administrator account is created, the setup endpoint is automatically disabled for security. If you need to reset the platform, contact your infrastructure administrator.
2.2 Daily Login
After the initial setup, all users log in through the standard login page. Enter your registered email and password, then click "Sign In." If your account has two-factor authentication enabled (available for Super Admin and Platform Admin roles), you will be prompted to enter a TOTP code from your authenticator app after the primary password verification succeeds. The refresh token system ensures you stay logged in throughout the day without needing to re-enter credentials, as long as you remain active.
2.3 Password Recovery
If you forget your password, click the "Forgot Password" link on the login page. Enter your registered email address, and the system will send a secure password reset link. This link expires after a configurable time period for security. Click the link, enter your new password (meeting the same strength requirements as initial setup), and confirm. Your existing sessions will be invalidated, requiring a fresh login on all devices.
Chapter 3
User Roles and Permissions
HubSphere implements a comprehensive Role-Based Access Control (RBAC) system with 13 predefined roles. Each role has a specific set of permissions that determine which features and data the user can access. The Super Admin has platform-level access across all tenants, while company-level roles are scoped to the user's own tenant. Understanding these roles is essential for proper access management within your organization.

Permissions follow a module.action format, such as leads.view, deals.create, dashboard.view. With over 224 permissions available, the system provides extremely granular access control. Tenant Owners and Super Administrators automatically bypass all permission checks, ensuring they always have full access to their respective scopes. Admin users can assign and revoke roles for users within their tenant through the Admin panel.
Chapter 4
Dashboard and Navigation
After logging in, you land on the main Dashboard which provides a high-level overview of your organization's activity. The dashboard displays key performance indicators (KPIs), recent activity feeds, quick-action shortcuts, and summary charts that update in real time. The navigation sidebar on the left provides access to all modules: CRM, HRMS, Communication, Automation, Analytics, and AI. Each module expands to reveal its sub-sections.
Dashboard Features

CRM Summary: Total leads, conversion rate, active deals, pipeline value, and recent lead activity with trend indicators showing month-over-month changes.

HRMS Summary: Total employees, attendance rate, pending leave requests, open positions, and upcoming payroll dates for the current period.

Communication Summary: Messages sent, delivery rate, template usage, and recent conversation activity across all channels.

Quick Actions: Create new lead, add employee, send message, create workflow, and generate report shortcuts for the most common tasks.

Use the sidebar navigation to move between modules. Click on a module name to expand its sub-menu, then click on a sub-item to navigate to that page. The breadcrumb trail at the top of each page shows your current location within the application hierarchy. You can also use the global search bar at the top to quickly find records across all modules by typing a name, email, or phone number.
Chapter 5
CRM Module
The CRM module is the core of HubSphere, providing comprehensive tools for managing your sales pipeline, customer relationships, and business development activities. It encompasses lead management, contact management, company tracking, deal pipeline, task management, follow-up scheduling, and note-taking. Every interaction with a prospect or customer is tracked and organized in a unified timeline view.
5.1 Managing Leads
Leads are potential customers who have shown interest in your products or services. To create a new lead, navigate to CRM > Leads and click the "New Lead" button. Fill in the required fields including first name, last name, email, phone, and source. You can also assign the lead to a sales executive, add tags for categorization, and set an estimated deal value. Once created, leads move through a configurable pipeline from initial contact through qualification, proposal, negotiation, and finally conversion to a deal.
  1. View all leads in a sortable, filterable data table. Use column headers to sort by any field. Apply filters by status, source, assigned executive, or date range.
  2. Click on a lead to open its detail view. Here you can see all contact information, activity timeline, associated notes, follow-ups, and related deals.
  3. Convert a lead to a deal when it qualifies. The conversion process creates a Company record (if new), a Contact record, and a Deal record, preserving all history.
  4. Bulk actions: Select multiple leads using checkboxes to perform bulk assignments, status changes, or export operations.
5.2 Deals and Pipeline
Deals represent active sales opportunities with qualified prospects. Navigate to CRM > Deals to view your sales pipeline organized by stage. HubSphere supports customizable deal stages that match your sales process. Each deal tracks the company, primary contact, deal value, expected close date, probability percentage, and assigned team members. Drag and drop deals between stages to update their progress, or use the detail view to edit all properties and view the complete activity history.
5.3 Contacts and Companies
The Contacts section (CRM > Contacts) maintains a detailed directory of all your business contacts. Each contact record stores personal information, job title, company association, communication history, and associated deals. The Companies section (CRM > Companies) tracks organizational accounts with company name, industry, website, employee count, and associated contacts. Both sections support full CRUD operations, search, filtering, and export to CSV format for external analysis.
5.4 Tasks, Follow-Ups, and Notes
Stay organized with the built-in task management system (CRM > Tasks). Create tasks with due dates, priorities (low, medium, high, urgent), and assign them to team members. Tasks can be linked to leads, deals, or contacts for contextual organization. The Follow-Ups section (CRM > Follow-Ups) lets you schedule and track customer interactions, ensuring no opportunity falls through the cracks. Notes (CRM > Notes) provide a free-form space for recording meeting notes, call summaries, and important observations linked to any CRM record.
Chapter 6
HRMS Module
The Human Resource Management System (HRMS) module provides a complete suite of tools for managing your workforce. From employee onboarding and department management to attendance tracking, leave management, expense claims, and payroll processing, the HRMS module covers every aspect of human resource administration. It is designed to serve organizations of all sizes, from small teams to large enterprises with complex hierarchical structures.
6.1 Employee Management
Navigate to HRMS > Employees to view and manage your workforce directory. Click "Add Employee" to create a new record with personal details, employment information, department assignment, designation, reporting manager, and compensation details. Each employee profile provides a comprehensive view including attendance history, leave balances, expense claims, and document attachments. The employee list supports filtering by department, designation, status (active/inactive), and employment date range.
6.2 Department and Designation Setup
Before adding employees, set up your organizational structure using HRMS > Departments and HRMS > Designations. Create departments (e.g., Engineering, Sales, Marketing, HR, Finance) with optional parent-child relationships for hierarchical organizations. Designations define job titles and their associated pay grades. Proper setup of departments and designations ensures accurate reporting and streamlined employee management across the platform.
6.3 Attendance and Leave Management
The Attendance section (HRMS > Attendance) allows HR managers to record daily attendance, track late arrivals and early departures, and generate attendance reports. Employees can clock in/out through the self-service portal. The Leave Management system (HRMS > Leave) supports multiple leave types (casual, sick, earned, maternity/paternity) with configurable annual balances. Employees submit leave requests that route to their reporting manager for approval. The system automatically tracks leave balances and prevents over-allocation beyond the available balance.
6.4 Payroll and Expenses
The Payroll section (HRMS > Payroll) enables HR managers to process monthly salary payments. Configure salary components (basic pay, HRA, allowances, deductions) per employee, generate payroll runs for specific periods, and export pay slips. The Expenses section (HRMS > Expenses) allows employees to submit expense claims with receipt attachments. Managers review and approve or reject claims, which are then reflected in the next payroll cycle. All financial data is strictly scoped to the tenant, ensuring complete data isolation between organizations.
Chapter 7
Communication Module
The Communication module centralizes all outbound and inbound messaging across multiple channels including email, SMS, and in-app notifications. Navigate to Communication in the sidebar to access the communication dashboard, which provides an overview of messages sent, delivery rates, and engagement metrics. The module is designed for both one-to-one conversations and bulk communication campaigns, making it suitable for sales outreach, marketing campaigns, and internal announcements.
7.1 Message Templates
Navigate to Communication > Templates to create and manage reusable message templates. Templates support dynamic variables (e.g., {{first_name}}, {{company_name}}) that are automatically populated when sending messages. Create templates for common scenarios such as welcome emails, meeting reminders, invoice notifications, and follow-up sequences. Each template has a name, subject line, body content, and associated channel (email or SMS). Templates can be cloned and edited for quick variations without starting from scratch.
7.2 Sending Messages
Use Communication > Inbox to view and manage conversations. The Send Message functionality allows you to compose and send messages to individual contacts or groups. For bulk communication, use the Bulk Send feature to deliver messages to a filtered list of contacts. The communication providers (email SMTP, SMS gateway) are configured by the Communication Manager through Communication > Settings. The system also supports webhook integration for receiving incoming messages from external providers.
Chapter 8
Automation Module
The Automation module enables you to create custom workflows that automatically execute actions based on defined triggers and conditions. This eliminates repetitive manual tasks, ensures consistency in business processes, and improves operational efficiency. Navigate to Automation > Workflows to view existing workflows and create new ones. The automation dashboard shows the total number of workflows, active vs. paused status, recent execution history, and success/failure rates.
  1. Create a workflow: Click "New Workflow" and define a name, description, and the trigger event (e.g., "New Lead Created", "Deal Stage Changed", "Employee Joined").
  2. Define conditions: Add conditional logic to control when the workflow executes. For example, only trigger when a deal value exceeds a certain threshold or when a lead source is "Website."
  3. Add actions: Specify what happens when the workflow triggers. Actions include sending an email, creating a task, updating a record, assigning to a user, or calling an external webhook.
  4. Activate: Toggle the workflow to "Active" status. It will now run automatically whenever the trigger event occurs and conditions are met.
Tip: View execution history in Automation > Executions to monitor workflow performance, debug failed runs, and optimize your automation rules. Each execution log shows the trigger event, condition evaluation results, actions performed, and any error messages.

Chapter 10
AI-Powered Agents
HubSphere includes five specialized AI agents that provide intelligent assistance across different business functions. Each agent is designed to understand the context of its domain and provide relevant, actionable insights. Navigate to AI > Chat to interact with the agents. The AI module requires an AI provider (such as OpenAI or Anthropic) to be configured by your administrator before use.
Available AI Agents

NOVA (Business Copilot): General business intelligence agent that can answer questions about your CRM data, generate reports, and provide strategic recommendations based on your sales pipeline and customer data trends.

VOX (Communication): Specialized in communication optimization. VOX can draft email templates, suggest message timing, analyze communication patterns, and recommend follow-up strategies for improved engagement.

SALESPRO (Sales): Your sales intelligence assistant. SALESPRO analyzes deal pipelines, identifies at-risk deals, suggests next-best-actions for sales executives, and provides competitive analysis based on deal history.

PEOPLEMIND (HR): HR-focused agent that assists with workforce planning, policy queries, employee engagement analysis, and compliance requirements. It can draft HR communications and summarize team performance.

INSIGHT (General): A versatile agent for cross-functional analysis. INSIGHT can connect data points across CRM, HRMS, and Communication modules to surface hidden patterns and provide holistic business insights.

Chapter 11
Super Administration
The Super Admin panel is accessible only to users with the SUPER_ADMIN role. It provides platform-level controls for managing all tenants, system-wide configuration, and cross-tenant analytics. This section is specifically for platform operators who manage the HubSphere infrastructure and oversee all customer organizations. Navigate to Super Admin in the sidebar to access these features.
11.1 Tenant Management
The Tenants page (Super Admin > Tenants) displays all organizations on the platform. Each tenant record shows the organization name, slug identifier, status (active/suspended), subscription plan, user count, and creation date. Super Admins can create new tenants, suspend or reactivate existing ones, and view detailed tenant configurations. When creating a new tenant, you define the organization name, admin email, and initial plan allocation. The system automatically provisions the tenant and sends an invitation email to the designated administrator.
11.2 System Configuration
The Settings page (Super Admin > Settings) provides platform-wide configuration options including default subscription plans, feature flags, AI provider configuration, email service settings, and security policies. Changes made here affect all tenants on the platform. The Roles page (Super Admin > Roles) allows viewing and managing the 13 system roles and their associated permissions at the platform level. The Audit Log (Super Admin > Audit) provides a comprehensive, searchable log of all administrative actions across all tenants, essential for compliance and security monitoring.
Security Note: Super Admin accounts support TOTP-based two-factor authentication. Navigate to your profile settings to enable 2FA. This is strongly recommended for all Super Admin accounts to prevent unauthorized access to platform-level controls.
Chapter 12
Tenant Administration
The Admin panel is available to users with TENANT_OWNER or ADMIN roles within their organization. It provides tenant-level management capabilities including user management, role assignments, membership control, and tenant-specific settings. Navigate to Admin in the sidebar to access these features. The Admin panel is the primary control center for day-to-day organizational management within HubSphere.
12.1 User and Role Management
The Users page (Admin > Users) lists all users within your tenant. Create new user accounts by specifying name, email, and initial role assignment. Edit existing users to update their information, change roles, or deactivate accounts. The Roles page (Admin > Roles) displays all available roles and their permission sets. The Memberships page shows user-to-tenant associations and their current status, useful for organizations with complex team structures or multiple departments.
12.2 Tenant Settings and Audit
Configure your organization through Admin > Settings, where you can set the company name, default timezone, date format, notification preferences, and module-specific configurations. The Audit Log (Admin > Audit) provides a detailed record of all actions performed by users within your tenant, including who did what, when, and from which IP address. This is invaluable for compliance, security review, and operational troubleshooting. The Security page (Admin > Security) displays the current security configuration including active CSP policies, 2FA status, and rate limiting thresholds.
Chapter 13
Best Practices and Tips
To get the most out of HubSphere Enterprise V3, follow these best practices established from real-world usage patterns across organizations of various sizes and industries. These recommendations cover workflow optimization, data management, security hygiene, and team collaboration strategies that will help your organization maximize the value of the platform.
Data Management

Keep records updated: Assign responsibility for data quality. Outdated contact information leads to failed communications and missed opportunities.

Use tags consistently: Establish a standardized tagging taxonomy for leads and contacts. Consistent tagging enables powerful filtering and segmentation across the CRM module.

Leverage bulk operations: Use CSV import (CRM > Import) for initial data migration and bulk updates. Export data regularly for backup and external analysis.

Security Practices

Enable 2FA: All administrators and privileged users should enable TOTP-based two-factor authentication through their profile settings.

Review audit logs: Regularly review the audit log for suspicious activity. Look for failed login attempts, permission changes, and data exports.

Principle of least privilege: Assign users the minimum role necessary for their job function. Not every user needs ADMIN access; use specific roles like SALES_EXECUTIVE or HR_EXECUTIVE for targeted access.

Workflow Optimization

Automate repetitive tasks: Identify manual processes that happen repeatedly (e.g., lead assignment, welcome emails, task creation) and create automation workflows.

Monitor automation health: Check the Automation > Executions page weekly to ensure workflows are running correctly. Failed executions should be investigated and fixed promptly.

Use AI agents effectively: Ask specific, contextual questions to AI agents. Instead of "show me sales data," try "compare Q2 vs Q3 conversion rates for enterprise deals over $50K."
